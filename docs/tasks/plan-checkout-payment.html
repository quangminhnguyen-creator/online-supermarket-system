Global Constraints

  • Frontend-only; không sửa backend, database, DTO hoặc endpoint vì file tiến độ đánh dấu Backend Core đã hoàn thành 100%.
  • Mọi checkout/payment request phải gửi Bearer JWT; guest không gọi /checkout hoặc /checkout/payment.
  • Dùng đúng contract hiện tại: frontend client gọi postJson('/checkout') và postJson('/checkout/payment').
  • Không thêm dependency, promotion engine, admin order UI, order history đầy đủ hoặc payment provider SDK ở frontend.
  • Delivery dùng phí hiển thị 15000 để khớp backend hiện tại; Pickup có phí giao hàng 0.
  • Sau checkout thành công phải reload cart state để header badge và trang giỏ hàng không còn hiển thị snapshot cũ.
  • Copy giao diện bằng tiếng Việt; responsive từ 320 px; form, radio group, alert, loading và success state phải accessible.
  • Mỗi task thực hiện RED -> GREEN -> REFACTOR -> COMMIT và không stage thay đổi ngoài scope.

API Contract Đã Xác Nhận

ActionRequestSuccessError chính
Tạo đơn PickupPOST /api/checkout { fulfillmentType: "Pickup" }201 CheckoutResponse400 CART_EMPTY, 409 INSUFFICIENT_STOCK
Tạo đơn DeliveryPOST /api/checkout { fulfillmentType: "Delivery", recipientName, recipientPhone, deliveryAddress }201 CheckoutResponse400 thiếu thông tin giao hàng
Khởi tạo thanh toánPOST /api/checkout/payment { orderId, method }200 PaymentInitDto400 invalid method, 404 order not found
Thanh toán sandboxPaymentInitDto.checkoutUrl khác nullRedirect trình duyệt tới URL sandboxGiữ orderId để user có thể thử lại

Payment Status Flow Cần Giữ Đúng

  • /api/checkout chỉ tạo order và trả CheckoutResponse.payment.status = "Pending" như placeholder ban đầu.
  • /api/checkout/payment mới tạo bản ghi Payment; nếu method là COD thì backend trả PaymentInitDto.status = "PendingCollection".
  • Frontend vẫn gọi payment endpoint cho COD để backend ghi nhận payment method và chuyển order sang trạng thái xác nhận hiện tại.

  • Step 5: Cài submit handler và payment method state

    const [paymentMethod, setPaymentMethod] = useState<PaymentMethod>('COD')
const [isSubmitting, setIsSubmitting] = useState(false)
const [submitError, setSubmitError] = useState<string | null>(null)

function buildCheckoutRequest(): CheckoutRequest | null {
  if (fulfillmentType === 'Pickup') return { fulfillmentType: 'Pickup' }
  if (!recipientName.trim() || !recipientPhone.trim() || !deliveryAddress.trim()) return null
  return {
    fulfillmentType: 'Delivery',
    deliveryAddressId: selectedAddressId || null,
    recipientName: recipientName.trim(),
    recipientPhone: recipientPhone.trim(),
    deliveryAddress: deliveryAddress.trim(),
  }
}

async function handleSubmit(event: React.FormEvent) {
  event.preventDefault()
  if (!accessToken) return
  const request = buildCheckoutRequest()
  if (!request) {
    setSubmitError('Vui lòng nhập đầy đủ thông tin giao hàng.')
    return
  }

  setIsSubmitting(true)
  setSubmitError(null)
  const controller = new AbortController()
  try {
    const order = await checkoutApi.checkout(request, accessToken, controller.signal)
    const payment = await checkoutApi.initiatePayment({ orderId: order.orderId, method: paymentMethod }, accessToken, controller.signal)
    await reloadCart()
    if (payment.checkoutUrl) {
      window.location.assign(payment.checkoutUrl)
      return
    }
    // payment.status comes from PaymentInitDto, not Order.Status.
    navigate(`/shopping/checkout/success?orderId=${encodeURIComponent(order.orderId)}&paymentStatus=${encodeURIComponent(payment.status)}`)
  } catch (error) {
    if (!isAbortError(error)) setSubmitError(toCheckoutError(error))
  } finally {
    setIsSubmitting(false)
  }
}

    Store controller trong ref nếu cần abort khi unmount; disable toàn bộ form khi isSubmitting true.

    function toCheckoutError(error: unknown) {
  if (error instanceof ApiError && error.status === 400 && error.data?.message === 'CART_EMPTY') {
    return 'Giỏ hàng không còn sản phẩm.'
  }
  if (error instanceof ApiError && error.status === 409 && error.data?.message === 'INSUFFICIENT_STOCK') {
    return 'Một số sản phẩm không còn đủ tồn kho. Vui lòng quay lại giỏ hàng để cập nhật số lượng.'
  }
  if (error instanceof ApiError && error.status === 401) {
    return 'Phiên đăng nhập đã hết hạn. Vui lòng đăng nhập lại.'
  }
  if (error instanceof ApiError && error.status === 404) {
    return 'Không tìm thấy đơn hàng để thanh toán.'
  }
  return 'Không thể đặt hàng. Vui lòng thử lại.'
}
